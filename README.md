# 🔥 Shiv Shakti Heat Product — Industrial Heaters Web Portal

A high-performance, fully responsive, and SEO-optimized web application built for **Shiv Shakti Heat Product**, a premier ISO-certified manufacturer of industrial heating elements based in Faridabad, Haryana, India.

---

## 🌟 Key Features & Highlights

- **Modern & Responsive UI**: Built with Tailwind CSS, supporting both Light and Dark modes with automatic system preference detection.
- **Advanced SEO & Local Schema**: 
  - Optimized meta tags, keywords, and Open Graph previews for top search engine ranking.
  - Google Local Business `JSON-LD` structured data to rank higher in local search results and maps.
  - XML Sitemap and `robots.txt` configuration for rapid search crawler indexing.
- **Interactive Product Catalog & Filtering**: Seamless category switching for Cartridge, Band, Tubular, and Coil heaters.
- **Dynamic Technical Specifications & Lightbox**: Interactive diagram cards with click-to-zoom modal support for detailed internal component structures.
- **Direct WhatsApp Quote Integration**: Instant form-to-WhatsApp submission routing user specs directly to the engineering team.
- **Smooth GSAP Animations**: Powered by GreenSock (GSAP) and ScrollTrigger for fluid entrance effects.
